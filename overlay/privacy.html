Privacy policy: Ascension Bench overlay (Twitch extension)

What the extension is. A hover-tooltip overlay for the Ascension Bench channel (twitch.tv/ascensionbench), where language models play Slay the Spire. It shows the game information of the run on screen: the deck and card piles, relics, potions, the map, the player's powers and the enemies' intents, as tooltips and panels over the video.

What we collect from viewers: nothing. The extension has no sign-in, asks for no identity (no Twitch "request identity" permission), sets no cookies, stores nothing in the browser, and sends nothing a viewer types or clicks anywhere. It keeps no analytics. The only requests it makes are the ones every viewer's browser makes to load the page: the Twitch extension helper, a font, the game's static text and card images, and the current game state from our backend.

What the backend holds. Our backend (a Cloudflare Worker at https://overlay.ascensionbench.com) keeps one thing: the current game state of our own channel, as our streaming computer sends it (gameStateIndex, character, relics, deck, potions, map, powers, intents). It holds no viewer data. When a viewer's browser fetches that state, the Worker answers the request and keeps no record of it beyond Cloudflare's standard, short-lived request logs and metrics for the Worker (which, like any web server's, see the requesting IP address; we do not read, export or combine them). Updates reach viewers through Twitch's extension PubSub, which Twitch operates under its own privacy policy.

Third parties the overlay loads from. Each of these sees the ordinary HTTP request from the viewer's browser and nothing else from us:

  • Twitch (extension-files.twitch.tv): the extension helper script, required for every Twitch extension.
  • GitHub (raw.githubusercontent.com, the Spireblight/slay-the-relics repository): the game's card, relic and potion texts and card images, loaded exactly as the upstream Slay the Relics extension loads them.
  • Google Fonts (fonts.googleapis.com, fonts.gstatic.com): the Kreon font.

What is shown. Only information about the game being played on the channel. The overlay never shows chat, viewer names, or anything about who is watching.

Children. The extension is not directed at children and collects no data from anyone.
